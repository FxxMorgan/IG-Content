Repositorio de contenido creativo y plantillas interactivas para redes sociales, especialmente diseñado para crear contenido visual atractivo y dinámico para Instagram, Facebook, TikTok y otras plataformas.

## Contenido Disponible

### [FloresAmarillas](./FloresAmarillas/)
**Plantilla interactiva para el Día de las Flores Amarillas (21 de septiembre)**
- Animaciones de flores flotantes y pétalos cayendo
- 4 temas de color personalizables
- Diseño 100% responsive
- Editor integrado para personalización completa
- Sistema de auto-guardado
- Exportación de HTML/CSS personalizado

**Tecnologías**: HTML5, CSS3, JavaScript, Responsive Design

### [Login-Purple](./Login-Purple/)
**Formulario de login con diseño moderno y elegante**
- Tema morado con gradientes
- Sistema de autenticación PHP
- Diseño responsive
- Transiciones suaves y efectos visuales

**Tecnologías**: PHP, HTML5, CSS3, MySQL

### [VideoBackground](./VideoBackground/)
**Plantilla con video de fondo para contenido dinámico**
- Video de fondo responsive
- Overlay de contenido personalizable
- Optimizado para móviles
- Carga optimizada de medios

**Tecnologías**: HTML5, CSS3, Video API

## Uso Rápido

### 1. Clonar el repositorio
```bash
git clone https://github.com/FxxMorgan/IG-Content.git
cd IG-Content
```

### 2. Navegar al proyecto deseado
```bash
cd FloresAmarillas  # o Login-Purple / VideoBackground
```

### 3. Abrir en el navegador
- Para proyectos HTML: Abrir `index.html`
- Para proyectos PHP: Configurar servidor local (XAMPP, WAMP, etc.)

## Estructura del Proyecto
