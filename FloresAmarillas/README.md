#  Plantilla de Flores Amarillas - Día Especial

Una hermosa plantilla totalmente responsive y personalizable para celebrar el Día de las Flores Amarillas (21 de septiembre) con animaciones, efectos especiales y completa personalización.

##  Características

###  **Personalización Completa**
- **Nombres editables**: Personaliza el nombre del destinatario y remitente
- **Mensajes personalizados**: Edita los mensajes principal y secundario
- **4 temas de color**: Clásico, Atardecer, Dorado Real y Primavera
- **Cantidad de flores ajustable**: Desde 20 hasta 100 flores animadas

###  **Totalmente Responsive**
- **Diseño adaptable**: Se ve perfecto en móviles, tablets y desktop
- **Optimizada para touch**: Gestos de deslizar para acceder al editor
- **Tipografía escalable**: Texto que se adapta automáticamente
- **Flores responsive**: Animaciones optimizadas para cada pantalla

###  **Efectos Especiales**
- **Flores flotantes**: Fondo animado con flores que flotan suavemente
- **Pétalos cayendo**: Efecto de pétalos que caen continuamente
- **Brillos mágicos**: Pequeños destellos que aparecen aleatoriamente
- **Animaciones suaves**: Transiciones fluidas y naturales

###  **Funciones Avanzadas**
- **Auto-guardado**: La configuración se guarda automáticamente
- **Exportación**: Descarga HTML y CSS personalizados
- **Modo oscuro**: Soporte automático para tema oscuro
- **Impresión optimizada**: Diseño especial para imprimir

##  Cómo Usar

### **Paso 1: Personalización**
1. Haz clic en el botón **"✏️ Personalizar"** en la esquina superior derecha
2. Completa los campos:
   - **Nombre del Destinatario**: ¿Para quién es?
   - **Tu Nombre**: ¿Quién envía el mensaje?
   - **Mensaje Principal**: El saludo principal
   - **Mensaje Secundario**: Un mensaje más personal
3. Selecciona tu **tema de color** favorito
4. Ajusta la **cantidad de flores** con el control deslizante

### **Paso 2: Vista Previa**
- Los cambios se aplican **instantáneamente**
- Puedes ver el resultado mientras editas
- Las animaciones se actualizan automáticamente

### **Paso 3: Guardar y Compartir**
- Haz clic en **"📥 Descargar CSS"** para exportar
- Se descargarán dos archivos:
  - `flores-amarillas-para-[nombre].html` - Página completa personalizada
  - `styles.css` - Estilos personalizados
- Comparte directamente el enlace o sube los archivos a tu servidor

##  Personalización Avanzada

### **Para Desarrolladores**

Si quieres personalizar aún más la plantilla:

#### **Variables CSS Principales**
```css
:root {
    --primary-yellow: #FFD700;      /* Color principal */
    --secondary-yellow: #FFF700;    /* Color secundario */
    --accent-yellow: #FFEB3B;       /* Color de acento */
    --background-gradient-start: #FFF9C4; /* Gradiente inicio */
    --background-gradient-end: #FFECB3;   /* Gradiente fin */
}
```

#### **Añadir Nuevos Emojis**
En `script.js`, modifica:
```javascript
const flowerEmojis = ['🌻', '🌼', '🌸', '🌺', '🏵️', '🌷'];
const petalEmojis = ['🌼', '🌸', '🍃', '✨'];
```

#### **Ajustar Animaciones**
Modifica las duraciones en `styles.css`:
```css
@keyframes float {
    /* Personaliza la animación de flotación */
}
```

## 🔧 Resolución de Problemas

### **Las animaciones van lentas**
- Reduce la cantidad de flores en el editor
- Cierra otras pestañas del navegador
- Actualiza tu navegador a la versión más reciente

### **No se ve bien en móvil**
- Asegúrate de tener activado JavaScript
- Verifica que tu navegador sea compatible
- Prueba en modo vertical y horizontal

### **No puedo personalizar**
- Verifica que JavaScript esté habilitado
- Recarga la página (Ctrl + F5)
- Prueba en ventana de incógnito

### **La descarga no funciona**
- Permite descargas en tu navegador
- Verifica que no esté bloqueado por antivirus
- Prueba con otro navegador
