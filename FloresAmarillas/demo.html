🌻 Plantilla Flores Amarillas - Demo

🚀 Cómo usar la plantilla:

  1. Abre el archivo index.html en tu navegador
  2. Haz clic en "✏️ Personalizar" para abrir el editor
  3. Completa los campos con tus datos personalizados
  4. Selecciona tu tema favorito y ajusta las flores
  5. Descarga tu versión personalizada

💡 Tips y Consejos

  • Nombres cortos: Funcionan mejor visualmente
  • Mensajes personales: Añade recuerdos o bromas internas
  • Elige el tema correcto: Clásico para amistad, Atardecer para romance
  • Ajusta las flores: Menos flores para móviles, más para desktop
  • Guarda tu configuración: Se auto-guarda cada 5 segundos
  • Comparte fácilmente: Descarga y sube a tu servidor favorito
